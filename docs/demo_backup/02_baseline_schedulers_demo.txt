=== SCHEDULER ALGORITHM DEMONSTRATION ===
Showing how each traditional algorithm makes decisions
============================================================
Algorithm Descriptions:

FCFS: First-Come, First-Served: Assigns tasks to first available GPU in order
Round Robin: Round Robin: Cycles through GPUs in order, assigning to next available
Least Loaded: Least Loaded: Selects GPU with minimum queue + running tasks + memory usage

Mock GPU States for Decision Making:
GPU 0: Available, 50% memory, 2 tasks in queue
GPU 1: Available, 80% memory, 0 tasks in queue
GPU 2: Crashed, 30% memory, 1 task in queue
GPU 3: Cooldown, 60% memory, 3 tasks in queue

Mock Task: Video, 2.1GB, 1 steps

Algorithm Decisions:
FCFS: Would select GPU 0 (first available)
Round Robin: Would select next GPU in rotation
Least Loaded: Would select GPU 1 (lowest memory + queue load)
